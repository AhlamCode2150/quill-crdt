How this works

Every keystroke becomes a tiny operation in a Replicated Growable Array (RGA) — a conflict-free sequence CRDT implemented from scratch in this project. Operations are broadcast directly to connected peers over a WebRTC data channel. There is no application server: PeerJS's public broker is used only for the initial handshake that lets two browsers find each other.

Try it

  1. Copy the room link above.
  2. Open it in a second tab or another device.
  3. Type in either tab — it merges live in both.
  4. Click Go offline, keep editing in both tabs, then reconnect — watch it merge cleanly.
